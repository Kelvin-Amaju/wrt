# Test Runs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Test Runs placeholder into a working local-first cross-browser QA runner with a visual step builder, lightweight concurrency limits, live logs, and saved in-memory run results.

**Architecture:** Keep browser execution in Electron's main process and expose a narrow IPC bridge through preload. The React renderer owns the form, visual step builder, and live result display; shared TypeScript types define run configuration and validation. Playwright is loaded only when a run starts, so no browsers remain active while OrbitQA is idle.

**Tech Stack:** Electron, React 19, TypeScript, Vite, Vitest, Playwright

**Spec:** Conversation-approved V1 scope: Windows-only, local-first, Chromium + Firefox + WebKit, visual builder plus advanced mode later, default concurrency 3 with queueing, authorized website QA only.

## Global Constraints

- Windows-only V1.
- Local-first; no sign-in or cloud dependency.
- Default concurrency is 3 and user-selectable concurrency is capped at 5 in this milestone.
- Browser processes launch only for an active test and are closed after completion or failure.
- Supported browsers: Chromium, Firefox, WebKit.
- Test actions in this milestone: open URL, wait, scroll, click, type, screenshot.
- The app is for authorized QA/testing, not artificial traffic or engagement.
