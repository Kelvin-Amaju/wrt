# OrbitQA v0.9 Device Realism & Consistency Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add truthful per-WorkUnit device consistency diagnostics and deterministic manual-QA pacing across desktop, Android, and iOS compatibility modes without adding stealth fingerprint spoofing.

**Architecture:** Add isolated pure modules for device consistency and pacing, wire them into the existing matrix runner, then expose the latest identity report in Test Runs. Keep privacy/proxy/timer/STOP paths unchanged and make Android critical contradictions fail closed while Local iOS host limitations remain warnings.

**Tech Stack:** Node.js CommonJS, Playwright, Electron, React 19, TypeScript, Vitest, Node test runner.

**Spec:** `docs/superpowers/specs/2026-09-16-v0.9-device-realism-consistency-design.md`

## Global Constraints

- No stealth, anti-detection, CAPTCHA bypass, fingerprint forgery, or unsupported hardware spoofing.
- Do not patch `navigator.webdriver`, canvas, WebGL, audio, sensors, battery, GPU, camera, microphone, or codec identity.
- Preserve max 50 WorkUnits and concurrency 1-5.
- Preserve per-WorkUnit timers, STOP-all behavior, proxy fail-closed behavior, screenshots, and safe blocker handling.
- Local iOS Compatibility must remain explicitly distinct from Real iOS.
